# 功能路线与状态

## 当前可用
- 按章节浏览中药资料；根据药名、性、味、归经、功效查找。
- 第六章27味样板数据（**待逐味复核**）。
- 错题和笔记关联药物/知识点，网页浏览器本地添加、编辑、JSON备份；按日期小日历查询。
- 可选 AI 安全中转示例；需要使用者自行部署。

## 正在逐步完善
- 药物横向对比：同屏列出2–4味药的性、味、归经、功效等，并高亮差异。
- 单味药详情扩展：教材能支持时逐味补充主治、用法用量、注意事项、配伍、鉴别点；未核实不填。
- GitHub Issue Forms：他人或自己可以提交资料到审核队列，审核后入库。

## 后续重要事项
- 逐味复核已录入27味解表药，对照用户提供的 PDF 修正数据。
- 按原书逐章录入其余中药，保留页码与核对状态。
- 错题去重、跨章节知识点专题归档、按日期回顾。
- 未来可做 GitHub App / 受保护服务端提交，实现网页同步，但需要身份认证、权限控制与成本评估。
- 浏览器端 E2E、移动端交互及无障碍体验校验。

## 不做
- 自动安排或强制打卡间隔复习。
- 前端存放长期服务商 API Key 或公开站点直接写 GitHub 主分支。
- 把尚未核对的章节、功效、用量和禁忌标记为已完成。
