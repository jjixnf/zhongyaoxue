# 错题、笔记和知识点提交工作流

## A. 直接在 ChatGPT 里提交（推荐用户本人）
1. 给出截图、原题文字、自己的选项/答案和想法；零散资料也可以。
2. 助手对照教材来源，分辨错因、修正明显识别错误并标记疑点。
3. 通过 `herbIds` 和 `knowledgeIds` 关联现有知识节点；新节点需要稳定 ID。
4. 对重复题/重复笔记做合并或增加引用，不覆盖已有个人原始记录。
5. 写入 `data/questions.json`、`data/notes.json` 或 `data/knowledge.json`，记录 `createdAt` 和 `updatedAt`，并向 `data/events.json` 加入真实日期事件。
6. 创建 PR、运行校验、合并，再从网页核对显示情况。

## B. 自己在线提交
1. 从 GitHub 仓库进入 **Issues → New issue**。
2. 选择「提交错题」「提交笔记/知识点」或「纠错/补充药物资料」模板。
3. 填写原始内容、相关药物名称/章节、参考来源；可粘贴截图到编辑器。
4. 提交 Issue 后先进入**待审核队列**，不会自动出现在网站里。
5. 维护者整理关联、校对、提交 PR、合并，最后在 Issue 里留下关联链接并关闭。
6. 其他同学也可提交，但没有仓库写权限者不能直接覆盖正式资料。

## C. 在网站使用“＋错题”“＋笔记”
- 当前版本写入浏览器 localStorage；可立刻在这台设备浏览、检索和日历查看。
- **这不是 GitHub 提交**。需要点击「导出我的记录」保存 JSON，之后将 JSON 发给 ChatGPT 或在 Issue 提交。
- 未来可增加受保护的登录/审核/提交队列，但不在公开静态页里嵌入 GitHub PAT。

## 资料类别和建议输入
### 错题
原题/选项，题目来源，原来选择与标准答案（不确定可空），错误原因（不确定则留空）、题目日期、药名或章节以及笔记/图片来源。
### 笔记
笔记原文、笔记性质（个人总结/记忆口诀/教材摘录/待核查）、关联药名及考点、参考来源或页码、创建日期。
### 药物资料/知识点
药名、分类章节、性味归经、功效、可选主治/用量/禁忌/配伍/鉴别点及每项出处，复核状态。

## 来源和时间
- 教材依据优先采用用户提供的《学霸笔记—中药学》，版本不同必须标注。
- GitHub 提交日期不等于用户首次做错题或写笔记的日期，旧记录需要保留真实日期，未知就标记未知。
- 统一显示北京时间/Asia/Shanghai 的自然日。日历不自动创建复习任务。
